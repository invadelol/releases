# Invade

Lightweight League of Legends overlay: in-game stats, runes and item recommendations, match history and game recording.

## Download

Get the latest installer from the **[Releases](../../releases/latest)** page:

| Platform | File |
| --- | --- |
| Windows (x64) | `Invade_*_x64-setup.exe` |
| macOS, Apple Silicon (M1 and later) | `Invade_*_aarch64.dmg` |
| macOS, Intel | `Invade_*_x64.dmg` |

Builds are not code-signed yet.

- **Windows**: SmartScreen may warn. Click **More info → Run anyway**.
- **macOS**: drag Invade to Applications, then right-click it → **Open** the first time. If macOS says the app is damaged, run `xattr -cr /Applications/Invade.app` once.

Once installed, Invade updates itself: it checks for new versions in the background and installs when you click **Update** (Settings → Updates).

## Privacy

Invade sends one anonymous usage ping per launch (app version, OS, and country derived from the connection, which is not stored) through [Aptabase](https://aptabase.com). No account, League name, game data or persistent identifier is sent. You can turn it off in Settings → Data.

This repository only hosts releases.
